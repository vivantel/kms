## Verdict

**Alignment is a cleanup.** Two conflicting items, both mechanical: the fact `kind` enum (resolve by admitting `derived`/`mixed` as optional values or migrating the 5 go-getter facts) and the INDEX format (pick the generated, always-quoted, sorted form as the core format; kms's checker already parses either). The go-getter-only items are an extension namespace (`go-getter:` key) plus two small optional additions that can move into the core as optional fields. The one corpus-scale effect is B1: dropping `track` touches 213 go-getter files, a mechanical field deletion.
