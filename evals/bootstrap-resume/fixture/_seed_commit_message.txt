docs: add issue and PR templates

Two issue forms (bug report, skill proposal) instead of GitHub's
generic default set, since this repo's actual issue types are "a
skill/manifest misbehaves" and "propose a new skill or behavior
change" rather than generic software bug/feature categories. A
config.yml points free-form questions at Discussions instead of
forcing them into a form. The PR template mirrors the attribute
skill's own Why/What changed/Refs shape.
