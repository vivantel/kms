The two skills added by
`docs/decisions/0009-bootstrap-and-steward-skills.md` are named:

- `bootstrap` — directory `plugins/kms/skills/bootstrap/`, frontmatter
  `name: bootstrap`
- `steward` — directory `plugins/kms/skills/steward/`, frontmatter
  `name: steward`

`stewart` was considered and rejected as the name for the ongoing skill
— a typo, not a deliberate choice — and never appears anywhere in this
repo's history.
